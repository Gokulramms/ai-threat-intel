    CrowdStrike Falcon EDR Integration

    Real-time sensor telemetry, host containment, and behavioral detections

    🦅

    CrowdStrike Falcon Sensor Bus — Standby Mode

    Connect your CrowdStrike OAuth2 Client ID & Secret in .env to activate live device inventory queries, detection alerts, and host quarantine.

    OAuth2 Spec Ready Zero Mock Telemetry Endpoints: /devices/entities/hosts/v1, /detects/queries/detects/v1

    Connector Diagnostic & Live Test

    To activate live CrowdStrike telemetry:

    1. Open .env in your project directory.
    2. Set CROWDSTRIKE_CLIENT_ID=your_falcon_client_id
    3. Set CROWDSTRIKE_CLIENT_SECRET=your_falcon_client_secret
    4. Set CROWDSTRIKE_BASE_URL=https://api.crowdstrike.com (or your Falcon cloud region)
    5. Click Test Falcon OAuth2 above to verify your live connection.

    Elastic SIEM & Historical Event Pipeline

    Elastic Common Schema (ECS) search across authentication, network, and firewall telemetry

    ⚡

    Elasticsearch SIEM Engine — Standby Mode

    Connect your Elasticsearch cluster URL and API key in .env to query historical security events, audit records, and correlated Kibana detections.

    Elastic Common Schema (ECS) Zero Mock Telemetry Index Pattern: logs-*, security-*, audit-*

    Cluster Health & Diagnostic

    To activate live Elastic SIEM queries:

    1. Open .env in your project directory.
    2. Set ELASTIC_URL=https://your-elastic-cluster:9200
    3. Set ELASTIC_API_KEY=your_base64_api_key (or ELASTIC_USERNAME / ELASTIC_PASSWORD)
    4. Click Test Elastic SIEM above to verify your cluster status.
